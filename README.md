A program that writes one funny line pitching the worst pizza topping imaginable (175 characters, one line) to `/output/entry.txt` — our new pizza, topped with the health inspector's 14-page report, laminated and lightly salted, served before Inspector Ramos could finish reading the part about the rats.

## Run it

```sh
node main.ts && cat /output/entry.txt
```
